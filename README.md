# Бот ВКонтакте для отеля «Морской бриз»

MVP-бот для ВКонтакте, который помогает гостям отеля узнать об услугах, ценах и связаться с менеджером для бронирования. Учебный проект.

## Возможности

- **Главное меню** — приветствие с кнопками навигации
- **Список услуг** — выбор из 5 пунктов (номера, завтрак, трансфер, СПА)
- **Карточка услуги** — описание и цена с кнопкой «Забронировать»
- **Прайс-лист** — общий перечень цен
- **Заявка менеджеру** — сбор контактов и дат заезда; бот подтверждает получение

## Установка и запуск

### 1. Клонирование / подготовка

Файлы проекта уже находятся в директории. Перейдите в неё:

```powershell
cd "VK product selection assistant"
```

### 2. Виртуальное окружение (Python 3.12)

```powershell
py -3.12 -m venv .venv
.\.venv\Scripts\Activate.ps1
```

### 3. Установка зависимостей

```powershell
pip install -r requirements.txt
```

### 4. Настройка секретов

Скопируйте шаблон и заполните значения:

```powershell
Copy-Item .env.example .env
notepad .env
```

| Переменная | Описание | Где взять |
|---|---|---|
| `GROUP_TOKEN` | Ключ доступа сообщества | Управление сообществом → Работа с API → Ключи доступа |
| `GROUP_ID` | Числовой ID сообщества (без минуса) | Управление сообществом → Адрес и название |

### 5. Настройка сообщества ВКонтакте

1. Откройте настройки сообщества
2. Включите **Long Poll API** (Работа с API → Long Poll API)
3. Разрешите тип события **Входящие сообщения**
4. Убедитесь, что бот (или приложение) привязан к сообществу

### 6. Запуск

```powershell
python bot.py
```

Остановка — `Ctrl+C`.

```
     [Главное меню]
```

### Маршрутизация

Бот распознаёт команды двумя способами:

1. **Payload кнопок клавиатуры** — JSON-поле, например `{"cmd": "service", "id": "spa"}`
2. **Текст сообщения** — текстовые кнопки ВК дублируются в поле `text`, бот приводит к нижнему регистру и ищет совпадения

Неизвестные сообщения вне режима заявки показывают главное меню.

### Внутреннее состояние

Каждый пользователь имеет запись в словаре `user_states` с тремя полями:

- `screen` — текущий экран (`"main"`, `"services"`, `"service"`)
- `service_id` — ID выбранной услуги
- `awaiting_request` — флаг режима приёма заявки

## Ограничения MVP

| Аспект | Реализация |
|---|---|
| Хранение заявок | В памяти процесса — теряется при перезапуске |
| Парсинг заявки | Принимает любой текст, без валидации формата |
| Ошибки сети | Логируются, бот перезапускает Long Poll |
| Ошибки VK API | Перехватываются, не останавливают бота |
| Конкурентный доступ | Нет (однопоточный, одна сущность бота) |

## Управление Long Poll

Бот обрабатывает все коды `failed`:

| Код | Действие |
|---|---|
| 1 | Обновить `ts`, продолжить опрос |
| 2, 3 | Перезапросить `server`, `key`, `ts` |
